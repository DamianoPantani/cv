Damian Szafulski's CV

# Pre-requirements

1. Node - version 22 or never recommended
2. npm - version 11 or never recommended

# Installation

Against the root directory, run: `npm i`

# Running the CV

To run CV in development mode (the only supported in this project) run `npm start`. If installation process went successfully, your browser should automatically open at http://localhost:3000, with no compilation errors.

# Generating PDF

Make sure application runs correctly. Against the root directory, run: `npm generatePdf`. Generated file should automatically open in default app configured in your system
